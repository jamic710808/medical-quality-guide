GitHub Pages 與 Vercel 提供靜態導覽；Python 後端及資料庫需依運行手冊另行準備，不因原始碼上傳就已部署。此輪只核對同步內容與 Python 語法，沒有重跑應用完整測試或宣稱臨床驗收。

動畫工程程式可供檢視，配音與資產未隨本次程式碼同步；完整可編輯媒體包保留於既有本機交付。
