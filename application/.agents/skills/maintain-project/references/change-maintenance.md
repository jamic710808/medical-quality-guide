# 變更與文件維護

## 按最高受影響範圍定位

| 本輪變化 | 按職責定位的現有文件 | 不自動擴展的範圍 |
| --- | --- | --- |
| 產品目標、範圍或驗收 | 當前需求與驗收約定，以及受影響的設計或功能說明 | 不重寫無關需求 |
| 跨功能的共享行為或數據含義 | 共享設計或接口約定，以及直接受影響的功能說明 | 不因名稱相似修改獨立功能 |
| 局部功能、頁面或操作行為 | 對應設計、功能說明或接口約定；使用方式改變時同步使用說明 | 不強制重跑整個文檔鏈 |
| 原型反饋與體驗調整 | 已有原型設計、對應源碼和驗看記錄；按影響判斷需求看板與使用說明 | 不把演示方案、模擬規則或待討論反饋升級為正式業務批准 |
| 行為不變的修復或實現調整 | 確有變化的實現說明或現有任務記錄，以及實際驗證記錄 | 不為讓檢查通過而觸碰未受影響的需求、設計或業務約定 |

實際文件職責由項目約定決定。找不到某類文檔時，先查已存在的等價文件；本輪需要新的行為說明而確無承載位置時，創建一份最小記錄即可，不製造平行事實源。

項目已採用 PRD、總 Spec、Feature Map、Feature Spec、Plan / Tasks 等結構時，按其既有層級和歸屬同步受影響內容。這些是可適配的項目合同，不是調用本 Skill 的前提；沒有這套結構的項目不據此補建。

## 當前約定與歷史過程

- 當前設計、需求和規格原位更新。已有編號繼續使用；刪除或替換行為有明確範圍，相關入口和遷移影響一併處理。
- 原始需求與客戶原件只讀。把新輸入寫入當前設計、規格或已有修訂區，並註明“本輪用戶要求”“測試假設”等實際來源。
- 同一份計劃和任務繼續記錄進度、偏差、未完成項和證據位置。已完成任務不抹除；後續新增工作使用新任務，行為變化時修訂當前規格並說明舊證據的適用範圍。
- 驗證記錄包含檢查對象、實際命令或操作、結果和未驗證項。不能以修改時間、文件被觸碰或輸出裡出現 PASS 代替實際行為證據。
- AGENTS 保存項目入口和長期規則，Skill 保存可複用流程；每輪業務進度不寫成新的全局規定。

## 接手與證據複用

明確項目和本次功能 → 讀取當前相關文件 → 對照實際源碼與已有結果 → 從未完成項繼續。

運行記錄只輔助本輪檢查，刪除後仍能依靠項目文檔接手。代碼、相關配置、檢查腳本或輸入改變時，只讓依賴它們的舊證據失效；不能複用過期結果，也不為安心重複執行未受影響的檢查。

## 不同項目的適配示例

- **原型反饋**：更新相關體驗設計與同一個演示工程，驗看受影響的操作；需求背景與看板是否變化單獨判斷，待討論反饋保留確認狀態。
- **接口變更**：更新對應實現、已有接口約定及直接受影響的調用方說明，用實際請求、響應與相關調用驗證。
- **命令行工具或處理腳本**：更新相應實現，按影響同步參數、輸入輸出或使用說明，用代表性輸入驗證結果與退出狀態。

這些是文件職責與驗證方法的說明，不是固定文件清單，也不表示所有場景都已實測。使用當前項目已有的路徑和有效約定，驗收圍繞本輪可觀察行為、相關文檔和實際證據。
