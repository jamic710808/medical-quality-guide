# 從選型推進最小構建

在用戶請求驗證或實現時使用本參考。僅諮詢時輸出必要設計即可；不要因參考裡存在構建步驟就安裝軟件、訪問新服務或覆蓋項目狀態。

## 先複用實際工程

讀取適用工程約定、受影響入口/出口、既有查詢與數據合同、相關實現和測試。框架、模型及部署已明確時沿用；舊入口和狀態需要改變時，顯式說明替代與遷移影響。

確定本次最小範圍：哪些問題、哪些來源與版本、哪些模塊/索引、怎樣啟動查詢、怎樣證明目標成立。用戶已有授權足夠時繼續，不把“先展示方案”強制變成新的確認關卡。需要新的費用、憑據使用或外發範圍時，只詢問具體缺項並繼續獨立工作。

本 Skill 提供代理執行的指導，不附帶所有框架的運行適配器。選中路線尚無現成實現時，可在授權項目中補最小實現並驗證，不必先開發通用插件平臺；存在關鍵阻塞就明確當前完成範圍，不用替身結果宣稱真實運行。

## 各路線的最小實現結果

| 選定能力 | 至少實現什麼 | 用什麼證明 |
| --- | --- | --- |
| 精確 / 全文 / 基礎向量 | 聲明範圍的索引或直接讀取、查詢入口、源 ID/版本引用、無答案出口 | 已知原文證據的查找與回放；邊界樣本；沒有向量模型時不稱向量檢索 |
| 關鍵詞＋向量融合 | 各路獨立查詢、相同訪問範圍、融合/去重、必要重排、保留命中軌跡 | 與合適單路基線比較，檢查專名/編號與改寫問法、更新/刪除；融合分數不冒充概率 |
| SQL＋文本路由 | 業務口徑與粒度映射、受限只讀查詢、結果範圍、解釋用文檔檢索與證據合併 | 獨立計數/集合結果和條款引用；查詢受表/列/行權限、超時/結果上限約束，不能只靠提示詞或 SELECT 前綴 |
| 文檔層級 / 樹導航 | 來源結構或摘要樹、查詢路徑、終端原文取回與預算/停止條件 | 跨章節代表問題、錯誤路徑/無答案，最終回到原始片段；摘要錯誤不能變為原文事實 |
| 圖檢索 / GraphRAG | 有據實體身份與邊、源回鏈、任務適合的查詢模式、必要圖擴展及索引更新 | 對有關係需求的樣本檢查邊/路徑支持和答案，圖不存在/權限撤銷時明確失敗；不要求一開始搭所有模式 |
| 本體 / 語義層 | 支持當前問題的術語、映射、關係與約束，實際來源證據和消費接口 | 口徑/單位/身份/粒度的正反例與可執行查詢；遵守所選本體系統原有 Schema，不等同建好整個領域知識庫 |
| 多步 / Agent 編排 | 在已有可用工具上增加路由、必要分解、狀態、每步證據及有界停止 | 固定多來源任務、缺來源/工具失敗/衝突退出；不以反覆模型自評代替目標驗證 |

建索引前保留版本化來源與定位；直接讀取/SQL 不必為了形式統一複製成向量片段。原始數值、關係、精確結果和文檔摘要分別表示，最終可回到真實輸入。


## 消費治理後的輸入

建設前區分“讀出來”“質量可用”“本次用途獲准”和“專業/業務資格成立”。複用上游 manifest 與合同；沒有采用 EvidenceItem 時要求等價語義，不強制遷移。

| 輸入狀態 | 消費決定 |
| --- | --- |
| 原值、版本、定位、角色/用途、當前授權與必要質量均明確 | 在該範圍構建所選最小查詢/檢索路徑 |
| partial 且 usable_scope 明確 | 可用部分單列；不能用於要求完整文書/集合的缺失或全量判斷 |
| 解析成功但規則未審核/用途不明 | 按實際允許目的限制；不能默認變成生產知識依據 |
| 臨床主體/單位/身份/關係未知 | 保留原文與未知，相關語義/聚合/圖邊不自動確認 |
| 參考答案、驗證/留出內容 | 留給獲授權 Evaluator，不混入建設索引、提示或本體 |
| 來源撤權/失效、版本不兼容 | 拒絕相關當前消費，不能以舊索引/緩存回退繞過 |

來源原文、規範化文本、索引文本/摘要和最終回答使用不同身份/版本。字符變化須能回到真實位置；新增標題/表頭不是源片段原字，無法映射時保留實際定位精度。chunk 不能跨患者/對象授權或互相矛盾的來源版本合併；父塊擴展、關係路徑和摘要也檢查允許範圍。

結構化數據保持原值/類型/粒度，不因選擇 RAG 就全量轉成自然語言。近重複用於檢索去冗餘或隔離評測汙染，不默認刪除業務記錄；同文本緩存複用也必須保持來源/權限隔離。建設分組沿項目邊界，不讀取留出答案選參數。

版本依賴覆蓋 source→evidence→cleaning/mapping→chunk→embedding/index。更新產生新派生版本，撤權先限制當前訪問後清緩存；舊版本保留用途不代表可繼續對新請求返回。輸入缺陷回交數據準備職責，不能靠擴大 top-k、改提示或生成補值掩蓋。

需要補清洗與交接策略時可讀取同級 [治理參考](../../prepare-business-data/references/data-governance.md)和[三類消費者交接](../../prepare-business-data/references/modeling-handoff.md)；缺少可選 Skill 時按項目合同落實同等邊界，不強制安裝它。

## 共同檢索響應與證據

優先映射項目已有響應合同；沒有時先固定最小必要語義，再實現具體序列化，不要求為了用 Skill 創建另一套通用平臺 Schema。

| 語義 | 必須能表達的內容 |
| --- | --- |
| 查詢與範圍 | 查詢/執行身份、所走路線、用途、來源與實際檢查範圍 |
| 命中證據 | 證據 ID、源版本、原文/原值或讀取引用、實際定位精度 |
| 派生結果 | SQL 計算、摘要、抽取邊或推斷的性質、輸入引用與產生過程 |
| 排序 | 原生分數、尺度/意義與融合/重排方式；不同分數不能直接作為統一可信概率 |
| 質量與出口 | 完整、部分、無答案、失敗或阻斷；未覆蓋範圍與缺口，恢復前提 |
| 過程版本 | 索引、嵌入、分塊、圖/語義模型、查詢/生成配置的適用版本 |

如上游已採用 EvidenceItem，沿用其身份/來源/locator；檢索命中、計算結果與摘要另記，不反向修改原始證據。沒有采用時不強迫遷移，只需保留等價可回查語義。

權限過濾應在證據進入模型/不可逆外發前成立。圖路徑、彙總、緩存與索引更新/刪除也要遵守原數據域；如果工具不能提供必要隔離，縮小實現範圍或報告缺項，不能只在最終回答刪名字。

## 構建順序與狀態

1. 固定本次方案與驗收任務，複用有效數據準備結果；讀取失敗或身份/業務定義未知的來源先限制消費。
2. 在項目自己的環境準備實際必需依賴，核對對應官方版本；使用已有注入配置或按當前憑據規則取值。不默認下載安裝所有候選或借用無關項目環境。
3. 構建一個能從真實入口查詢到可回查證據的最小路徑，再加有收益的能力；資源目錄、生命週期和重建依據明確，大產物生成前排除 Git。
4. 依 [驗證規則](evaluation.md) 檢查正常、無答案、失敗與直接受影響舊路徑；啟動成功、生成代碼、虛擬數據或 Mock 通過分別報告，不能當業務效果。
5. 新索引或接口通過後再切換本次允許的入口；保留舊有效狀態或明確恢復辦法，不用全工作區回滾處理局部失敗。
6. 交付實際命令/配置、輸入與結果版本、驗證證據和未滿足項；用戶只要求本地原型時到此停止，不自動部署或擴展 Feature。

推薦、可執行代碼、已運行與已驗收是獨立事實。用“已實現代碼但模型未配置，生成未驗證”等準確狀態，不讓一個完成勾選覆蓋所有階段。

## 與現有 Skills 的可選銜接

下表的同級 Skills 在本工作區可用；搬到其他環境先發現其是否存在。缺少可選 Skill 不阻止一般選型：沿用項目現有接口與工具；需要其專有運行時且不可用時準確說明缺項。

| 能力 | 何時使用 | 交接內容與限制 |
| --- | --- | --- |
| [prepare-business-data](../../prepare-business-data/SKILL.md) | 來源不可讀、缺定位，或需要數據畫像/規範化 | 指定路徑、用途、格式/覆蓋問題；不要把解析選型重做為 RAG 選型 |
| [build-ontology](../../build-ontology/SKILL.md) | 已確認需要其語義系統且尚無有效本體 | 工作負載、數據源、允許範圍與有據語義需求；先檢查實際 MCP/運行時。遵守 Term / Mapping / Relation / Constraint / Evidence 契約，不把任意圖模型冒充它 |
| [evolve-ontology](../../evolve-ontology/SKILL.md) | 已有本體且觀察到可歸因的能力缺口 | 現有版本、問題與有效軌跡；不重建/覆蓋當前版本，獨立評測邊界沿用原流程 |
| [feature-spec-planning](../../feature-spec-planning/SKILL.md) | 項目採用 PRD / PSC / Feature 鏈，用戶要求詳細計劃 | 技術決定、輸入輸出、影響範圍和驗證；業務/共享語義變化先回對應事實源，不在局部實現偷加需求 |
| [project-evals](../../project-evals/SKILL.md) | 項目已經有 AC 或要求建立正式驗收 | 任務、預期、真實檢查入口與證據；沿用現有編號/記錄，不用 RAG 指標取代業務 AC |

未採用這些 Skills 的項目可直接完成同樣職責，不先補全這一整套流程。不要根據技術詞自動啟動本體建設、演化、項目初始化或部署。

外部可選參考：[Memgraph GraphRAG Skill](https://github.com/memgraph/skills/blob/main/skills/memgraph-graph-rag/SKILL.md)適合已選擇相應圖路線後的構建；[LangChain framework-selection（benchmark 資源）](https://github.com/langchain-ai/skills-benchmarks/blob/main/skills/benchmarks/framework-selection/SKILL.md)用於框架分層參考。它們不是本 Skill 的必裝依賴；引入前核對真實資源、許可、目標版本和所需權限。
