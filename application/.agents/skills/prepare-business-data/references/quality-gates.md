# 解析質量、路線比較與停止條件

## 先確定消費任務

區分只讀預覽、結構保留、可定位證據、表格分析、候選事實和建模輸入。以使用者確實需要的內容定義關鍵字段、結構與位置要求；沒有確認目標時提供條件化路線，不自定醫學正確率或生產 SLA。

來源權限、模型運行位置、預算及實際目標環境先作為篩選條件。路線失敗不自動授權外發、付費調用或更換服務。

## 代表性樣本與最小對照

按特性取樣，不按字母順序的前幾個文件代替覆蓋：
- 數據庫：已聲明/未聲明鍵、複合鍵、源類型與業務類型不同、原值/空值。
- CSV/JSON/GZ：前導零、長標識、引號內換行、嵌套/數組、缺失/null、長記錄與壓縮邊界。
- XML/XLSX/Markdown：段落屬性/命名空間、公式與空緩存、合併/隱藏、嵌套列表/代碼塊及位置。
- PDF：文本/掃描/混合、多欄、跨頁表格、圖注、低清或旋轉頁；只有實際存在時才納入。
- 圖像/波形：圖像真實用途、解碼/位深，頭和數據配對、通道/單位/樣本範圍；不能把資料元信息檢查說成診斷驗證。

確定性原生讀取滿足合同即可採用；不為了排名對 CSV 同時運行多個 LLM。質量不確定的文檔先選兩條有實質差別的候選；無須安裝和跑完所有框架。

## 分開的質量門檻

| 項目 | 觀察方式 | 失敗時怎麼辦 |
| --- | --- | --- |
| 輸入與覆蓋 | 對照本次聲明範圍、數量/頁/記錄/通道及未知總數；記錄未讀、失敗、部分成功 | 輸出準確範圍並隔離未通過部分，不能刪除失敗對象後報全量成功 |
| 原值與結構 | 核對編號、空值、數值精度、標題層級、表頭/單元格跨度、XML 屬性、波形單位 | 修正類型/佈局讀取，原件保持不變；保留原生結果用於複核 |
| 位置重放 | 從輸出指針回到同版本原頁/原記錄/原單元格/採樣區間，核對是否支持文本或數值 | 標記缺定位/定位錯，不能補造偏移或座標；阻止作為精確證據消費 |
| 統一契約 | 運行 JSON Schema 與單項語義校驗，檢查評測隔離和批次身份 | 先修適配器或交接數據，不修改來源以遷就 Schema |
| 業務語義 | 對候選實體/關係核對原文、否定、時間與適用條件；專業問題交對應負責人 | 保留候選/爭議，不作為已確認事實寫入本體 |
| 運行代價 | 在同樣樣本與範圍記錄耗時、峰值資源、產物體積、模型/費用與配置 | 僅在達到所需質量的候選中比較；沒量測的數值標未測 |

confidence 只保留工具原始值、尺度和含義；不同模型或版面的分數不能直接用來決定“最優”。JSON 序列化無損不等於前一步 OCR/抽取無誤。

治理/清洗還需核對變換是否改變了原值、身份、缺失或語境，以及文字/座標是否能回到同版原件；方法見[治理參考](data-governance.md)。質量發現與消費者的接受/限制/拒絕分開，未知總數或未配置檢查不報告通過；頁、記錄、對象等不同分母不能混加。是否需要專業審核由項目用途決定，不把每次格式讀取升級成完整業務驗收。

## 路線決定與回退

在項目記錄裡為每類輸入寫明：特性 → 主選與理由 → 何時換備選 → 輸出/定位 → 已驗/未驗 → 消費限制。勝出條件是滿足當前約束和質量門檻，再選擇成本/複雜度更低的方案；無法分出差異時可保留主選待驗證，不編造排名。

失敗只重試受影響部分。文本 PDF 可以回查原生字符，複雜佈局可換結構解析器，掃描件可換已批准 OCR 管線；每次變化記錄工具/版本/配置及新增外發或成本條件。未知不等於自動通過，難樣本不能從評測分母消失。

## 與建模/正式評測隔離

解析路線開發使用經允許的建設/調試樣本。若項目指定驗證或留出集合，不能用其答案調參或反向修改路線；抽取參考標註字段不是業務事實抽取。讀到結果的建模者不能再把同一結果當盲測證據。

噹噹前輸入、產物合同和直接消費路徑通過必要檢查時停止；只在輸入/配置/規則變更或具體失敗影響結果時複查相應部分。不要用重跑同一成功檢查替代真實下游驗收。
