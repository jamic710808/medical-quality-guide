## 安裝與構建

在一次性臨時目錄運行：

```sh
npx --yes shadcn@4.21.0 init --template vite --base radix --preset nova --no-monorepo --name prototype-smoke --yes
cd prototype-smoke
npx --yes shadcn@4.21.0 add dialog --yes
npm run build
npm run dev -- --host 127.0.0.1 --port 5178 --strictPort
```

結果：工程與 Button/Dialog 組件創建成功，TypeScript 和 Vite 構建通過，本地服務啟動成功。

初始化探索中發現 `--preset radix-nova` 被 CLI 拒絕；有效參數為 `--base radix --preset nova`。本安裝說明已經使用後者；生成配置中的 `style: radix-nova` 與 CLI 參數不能混淆。

腳手架生成的 `vite.config.ts` 使用 `__dirname`，Vite 提示未來原生配置加載器不支持該寫法。本次構建與運行均未被阻塞，沒有為這條未來兼容提示改寫上游腳手架。

## 基礎交互

臨時示例使用一個演示任務、React 內存狀態、Button 和受控 Dialog，支持確認、取消及恢復初始數據。它僅用於驗證技術棧，不是本技能附帶的業務模板。

內置 Browser 返回不可用，改用獨立的項目測試瀏覽器，沒有使用系統 Chrome 或已有登錄會話。

| 操作 | 觀察結果 |
| --- | --- |
| 打開桌面頁面 | 標題、狀態和按鈕正確顯示 |
| 查看後取消 | 彈窗關閉，狀態仍為“待確認” |
| 查看後確認 | 彈窗關閉，狀態變為“已確認”，重複確認按鈕禁用 |

| 點擊恢復演示數據 | 恢復“待確認” |
