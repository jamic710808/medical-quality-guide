# 正式應用字號與圖譜淺色調整

2026-10-14，按用戶反饋調整正式應用字體和知識圖譜默認主題。原問題來自大量 9～12px 的業務樣式，以及醫療圖譜首次進入被設為 Aurora；舊瀏覽器還會繼續沿用上游 `theme` 緩存。

## 已修改

- 導航、表格、正文、證據說明和常用操作提高到 16px；表頭和輔助業務信息為 14px，次要品牌/腳註最低 12px。維持標題/內容層級，控件允許合理換行。
- 圖譜默認白色畫布、淺色工具欄/檢查器。醫療偏好使用 `mq.graph.theme`，首次不再繼承上游深色緩存；之後用戶主動選擇的原生主題會保存。
- 原生節點/邊標籤分別提高到 22/14 個圖座標像素，選擇節點後居中且縮放至少 0.75，選中區域節點標籤實際至少 16.5px。容器隨側欄展開/摺疊調整，避免選中對象被檢查器擋住。總覽仍使用原生縮放和佈局。
- 圖譜探索欄、檢查器、路徑起終點控件適配新字號；原生渲染器、Designer、主題、搜索與路徑功能保留。

直接文件：`frontend/src/styles.css`、`frontend/src/pages/GraphPage.tsx`、原生 `OntologyGraph.tsx` 和 `SearchFilter.tsx`。設計規格與原生補丁說明同步。

## 驗證

- `npm --prefix frontend run build`：TypeScript 和 Vite 構建通過；本機應用已使用新生成的靜態資源，無需重啟業務服務。
- 項目隔離 Chromium 實測 1440×1000、1280×800：導航/表格/按鈕為 16px，表頭/來源為 14px，檢查器說明為 16px，圖譜背景為 rgb(255,255,255)，頁面無橫向溢出，控制檯無頁面異常。
- 注入舊 Aurora 緩存後，首次仍顯示淺色；手動選擇 Aurora 後刷新保持，再選淺色刷新仍保持。
- 搜索臨床斷言、選中居中、有向路徑、主題切換、命令面板均可操作；工作臺、病例證據、圖譜與 Designer 的截圖已實看。沒有提交或改寫臨床業務狀態。
