# F005 · 規則與知識版本治理規格

## 目標與可觀察結果

讓質控運行拿到適用、可回查且版本固定的規則和知識依據，讓規則維護者清楚候選、批准、生效與失效的區別。原文能查到、檢索能命中和允許用於生產判斷分別成立。

REQ-005 / S01-06 的依據版本混亂，落實為版本/用途/適用範圍治理；S01-08 的解釋無法回查，落實為原文定位；S01-05 的數據出域風險，落實為同授權域檢索與失效處置。混合檢索是實現這些能力的技術路徑，不新增通用知識庫業務。

本規格承接用戶本次選型落盤與 Feature 補充請求，業務邊界沿用已確認 PRD / PSC。ready 表示行為可進入規劃；[Plan](plan.md)為 draft，運行條件尚未驗證，Feature 仍 planned。

## 來源與範圍

- 來源需求：REQ-005, NFR-001, NFR-002, NFR-003, NFR-004, NFR-005。
- 來源總規格：PSC-001, PSC-004, PSC-008, PSC-009, PSC-012。
- 本 Feature 包含：8 條候選規則及知識依據的版本、用途、適用範圍、審核與生效/失效；按受限範圍取得原文/候選證據；索引版本、變更影響與可導出的規則知識基線。
- 本 Feature 不包含：不批准醫學指南、不編造審核意見，不做患者最終結論；F003 負責解析，F006 負責聯合判斷，F010 負責交付包裝。上游 98 項參考規則不自動併入本項目 8 條執行規則。

本期必須消費 F004 的已批准本體語義版本，用於術語定義、映射/值集和必要檢索擴展；規則專業資格仍由本 Feature 管理。沒有有效本體時依賴該語義的消費受限，精確來源查看/規則候選登記不偽裝為完整檢索已完成。

## 輸入輸出與迭代邊界

- 輸入與前置條件：F003 的規則/知識 EvidenceItem、來源類別/許可/定位/覆蓋，規則責任人及審核記錄，F001 的動作/數據域授權，以及 F004 的已批准 SemanticRelease、映射/值集和語義接口；檢索請求含用途、範圍、適用時間和所需版本。候選登記/原文查看可按既有條件獨立推進，完整語義消費不能跳過 F004 前置。
- 輸出、必要語義與消費方：可選或被拒絕的規則/知識版本、原文與檢索結果、適用/失效/衝突依據、變化影響和基線；供 F006/F008 固定使用，F010 消費已形成資產。
- 可獨立迭代：在上述合同不變時調整內部查詢、映射、檢索或呈現實現；不得靜默改變共享身份、狀態、適用性、原值和證據精度。
- 需要協調的變化：共同對象/版本、權限/用途、失敗與恢復、消費者可用範圍；先更新受影響總規格與 Map，技術細節在 Plan 和共享技術專題維護一處。

## 功能行為

### 主流程

1. 候選規則或知識來源時，登記/修訂版本；來源、適用範圍與用途可查，輸出原文和版本關係完整，交給授權維護者審核。
2. 具備適用審核條件時，按權限批准/生效或失效；保留批准/生效/加載時間區別，輸出責任記錄和實際結果一致，交給運行選擇版本。
3. 質控或規則查看請求時，按用途/範圍/版本檢索；返回實際證據和資格/缺口，輸出可回到原文且版本固定，交給F006/F008。
4. 來源、規則或權限發生變化時，重建/限制受影響檢索範圍；舊歷史可查但當前訪問仍校驗，輸出影響清單和當前可用範圍，交給重新選擇與核驗。

### 業務規則與邊界

- 每條規則的規則版本、知識來源版本與檢索索引版本分開；發佈、批准、業務生效和加載時間不可混稱最新。
- 離線驗證選擇候選需用途明確；未批准、範圍不明或衝突不能生產放行；索引發布不產生專業批准。
- 相同規則 ID 不同版本及同文不同來源保持獨立；指定規則不被相似條文替換。
- 檢索只提供候選依據；能定位不等於語義支持或適用於該病例。舊運行保持舊依據，導出不升級狀態。

## 異常與恢復

| 情況 | 可觀察狀態 | 系統行為 | 恢復 |
| --- | --- | --- | --- |
| 無匹配/無可用版本 | 空結果或明確未滿足資格 | 分別說明無命中與不適用 | 補充有效資料或選擇允許用途 |
| 向量分支不可用 | 實際檢索模式及受影響範圍 | 允許的原文查看可保留詞法結果；需要語義覆蓋的任務受限 | 修復域內模型後重試 |
| 定位失效/結構缺口 | 知識片段受限 | 不偽造片段或按完整依據消費 | 經 F003 修復後建立新版本 |
| 規則或用途衝突 | 拒絕受影響選擇 | 保留衝突和歷史，不用相似度裁決 | 責任人明確依據及範圍 |
| 責任記錄保存失敗 | 變更未完整成功 | 不顯示已正式生效/發佈 | 恢復保存並核對同一變更 |
| 權限撤銷/索引更新失敗 | 當前檢索限制受影響對象 | 舊索引不得重新暴露已撤銷內容 | 修復範圍/重建；歷史回查仍受授權 |

## 驗收標準

以下 AC 說明本 Feature 的貢獻。跨 Feature 的最終結果仍需 product 套件組合驗證；固定夾具和消費者替身不能代替真實專業驗收。

### AC-F005-001 · 規則知識身份與生命週期分離

- 來源：REQ-005, NFR-002, NFR-005, PSC-001, PSC-004
- 對應 PRD 驗收：AC-006
- Given 同一規則有 v1/v2，知識來源與發佈/批准/生效/加載時間不同，另有 98 項上游參考與本項目 8 條候選。
- When 登記和修訂規則/知識。
- Then 規則、知識、索引身份分開且有來源；候選不自動生效，舊版本可回查，上游參考不自動成為執行包。

### AC-F005-002 · 用途、範圍與授權共同決定可選依據

- 來源：REQ-005, NFR-001, NFR-003, PSC-004, PSC-008
- 對應 PRD 驗收：AC-006, AC-026
- Given 候選規則可用於離線驗證，但未批准用於生產；另有病種/語言範圍未知、過期授權和衝突生效版本。
- When 為給定用途和時間選擇依據。
- Then 只有資格與授權同時滿足的版本可用；不明確條件返回原因和衝突，不能默認選最新或越權讀取。

### AC-F005-003 · 原文、編號與上下文可準確回查

- 來源：REQ-005, NFR-002, PSC-001, PSC-004
- 對應 PRD 驗收：AC-006, AC-008
- Given 同編號不同版本條文包含否定、例外、表格及跨段說明。
- When 按編號或文字請求查看依據。
- Then 指定編號/版本不會被相似條文替換；返回支持理解的原文與父上下文、定位和來源性質，不能只返回生成解釋。

### AC-F005-004 · 問法變化召回仍保留共同證據語義

- 來源：REQ-005, NFR-002, NFR-003, PSC-001, PSC-004
- 對應 PRD 驗收：AC-006, AC-008
- Given 同一允許規則集有條號提問、中文改寫及中英術語變體，存在相近但不適用條款。
- When 在固定版本執行已聲明的檢索路線。
- Then 命中帶實際模式、原生名次/分數、資格及證據定位；近義不替代適用性，排序分數不變成醫學可信概率。

### AC-F005-005 · 無答案與部分檢索不偽裝完整依據

- 來源：REQ-005, NFR-002, NFR-003, PSC-001, PSC-004
- 對應 PRD 驗收：AC-006, AC-009
- Given 知識集無相關條款，或向量/解析/定位分支失敗，僅部分詞法結果可查。
- When 請求本次規則依據。
- Then 無命中、失敗、資格不明與部分結果分別表達，返回影響範圍；不編造指南、不用其他版本頂替，也不宣稱所需語義覆蓋已完成。

### AC-F005-006 · 更新、撤權與發佈保持責任一致

- 來源：REQ-005, NFR-001, NFR-004, NFR-005, PSC-004, PSC-008, PSC-009
- 對應 PRD 驗收：AC-006, AC-017, AC-026
- Given 新知識/分詞/模型產生候選索引，舊資料權限撤銷，且關鍵責任記錄寫入可失敗。
- When 更新規則資格或發佈檢索索引並恢復失敗。
- Then 資格與索引狀態分開；未完整提交不給成功，撤權內容不再進入模型/緩存返回；重試不重複生效，回退不重啟失效依據。

### AC-F005-007 · 運行與交付固定原有依據基線

- 來源：REQ-005, NFR-002, NFR-005, PSC-004, PSC-012
- 對應 PRD 驗收：AC-006, AC-023
- Given 舊運行引用 v1，當前已有 v2，一份資產基線同時包含候選與已批准資料。
- When 查詢歷史依據並向 F010 提供基線。
- Then 舊運行仍對應舊版本，原文回查受當前權限；基線包含用途/來源/狀態，不因導出或新版本出現改寫舊資格。

### AC-F005-008 · 故障不會擴大模型數據流

- 來源：REQ-005, NFR-001, NFR-003, PSC-004, PSC-008
- 對應 PRD 驗收：AC-006, AC-026
- Given 檢索請求可能含病例片段，本地嵌入不可用且配置含未授權外部端點。
- When 發起檢索或重試。
- Then 未授權提交被拒絕，正文不會進入普通錯誤日誌；語義分支不可用如實返回，不能把本地索引配遠程調用宣稱全程域內。
