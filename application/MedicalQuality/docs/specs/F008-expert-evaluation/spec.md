# F008 · 專家評測與分歧仲裁規格

## 目標與可觀察結果

以固定樣本/配置和真實獨立專家判斷評價一期質控能力，保留原始分歧、仲裁、覆蓋/棄答/失敗分母及高風險漏報。向 F009 交付能審查、可重算的評測證據，不讓平均分或模型輔助標籤替代專業責任。

本輪依據用戶“補齊全部方案、Feature 與評估”的授權，在原 Map 邊界內展開。Spec ready 表示業務行為已可據此規劃；Plan draft / Tasks planned 保留尚未取得的運行與專業證據，不宣稱功能已完成。

## 來源與範圍

- 來源需求：REQ-017, NFR-001, NFR-002, NFR-003, NFR-004, NFR-005, NFR-006。
- 來源總規格：PSC-001, PSC-008, PSC-009, PSC-010, PSC-011, PSC-013。
- 本 Feature 包含：批次/抽樣與分組邊界、固定版本、兩名專家獨立原判、爭議仲裁、指標/rubric、風險分層及變化比較、評測崗位界面、受控報告/審計和准入交接。
- 本 Feature 不包含：不從獨立答案構造本體/索引或提示，不由模型裁判替專家金標準，不批准上線、不代 F007 簽字，不偽造實際專家/基線/閾值。
- 產品含義以 [PRD](../../PRD.md)、[Product Spec](../product-spec.md)及 [Feature Map](../feature-map.md#f008) 為準；局部驗收貢獻與產品組合驗收分開。

## 輸入輸出與迭代邊界

- 輸入與前置條件：獲准樣本與來源角色、固定文書/證據/規則/知識/語義/模型配置、QualityRun/CheckResult、評測口徑/抽樣方案、具權限專家及凍結的職責；參考答案僅獲准 Evaluator 消費。
- 輸出、必要語義與消費方：EvaluationBatch、兩份不可相互覆蓋的 Judgment、獨立 Arbitration、版本固定的 MetricReport 與風險/缺項清單、責任記錄和 GateEvidence；F009 根據這些材料另行判定。
- 可獨立調整：本模塊內部組織、查詢與呈現方式，前提是身份/版本、狀態、允許範圍和證據合同不變。
- 需協調上下游：共享對象/版本/錯誤、授權和責任事件變化同步生產者與消費者，不在局部把未判斷改為通過。原始資料與既有原型保持；正式行為由後端事實源提供。

## 功能行為

### 主流程

1. 授權樣本與規則範圍時，準備並凍結批次；顯示來源/分組/版本/指標口徑，結果為不可漂移的樣本清單，交給兩位獨立專家。
2. 各自獲派樣本時，分別判斷問題/證據/風險；原判獨立保存、不用他人原判預填，結果為身份與證據可查，交給一致性計算/仲裁。
3. 兩份原判有分歧時，獲指派者裁決；原判保留，裁決追加，結果為裁決理由與剩餘問題，交給指標/門禁。
4. 凍結輸入與判斷時，運行/彙總指標；顯示分子分母、棄答/失敗與分層，結果為固定報告、不可判斷，交給F009/獲准查看者。

### 業務規則與邊界

- 兩份原判必須由不同實際身份完成；提交前不展示對方原判作為默認答案，仲裁不可覆蓋原判。
- 病例/文書/同文本或近重複族保持在一致的數據分區，建設輸入不能讀取驗證/留出答案或仲裁反饋調參。
- 統計單位、匹配口徑、專家真值與嚴重度由批次凍結；模型建議不自動成為參照。
- 無法判斷、讀取失敗、未執行和缺專家意見均顯式保留；不能從分母刪除困難項提高效果。
- 任何經專家確認高風險漏報及未解決高風險分歧/無法判斷應形成阻斷信號，最終准入由 F009 決定。

狀態名稱沿用 PSC 與主責模塊的共同含義；登記/計算/交接完成只說明該環節，不自動錶示專業確認或生產放權。所需技術字段在 Plan 與共享實施合同落實，本文不預填醫學閾值/真實賬號。

## 異常與恢復

| 情況 | 可觀察結果/處理 | 恢復條件 |
| --- | --- | --- |
| 缺兩份獨立原判 | 批次未滿足專業參照 | 補齊合法評測者，不算雙人一致 |
| 樣本/配置變更 | 新批次或明確重評 | 舊批次固定原版本，不能原地替換 |
| 無參照/零分母/未運行 | 指標未定義或未測 | 顯示原因，不填 100% 或 0 錯誤 |
| 授權撤銷/審計失敗 | 限制訪問/提交失敗 | 合法範圍恢復後對賬 |
| 高風險待仲裁 | 阻斷證據可見 | 完成真實專業處理與相關重驗 |

## 驗收標準

每項 AC 是本 Feature 的可觀察貢獻；固定夾具驗證機制，真實相鄰模塊與專業材料驗證端到端目標。未實現時用例 check_ref 保持 null。

### AC-F008-001 · 凍結評測樣本與完整配置

- 來源：REQ-017, NFR-002, NFR-005, PSC-001, PSC-010
- 對應 PRD 驗收：AC-019, AC-020
- Given 同病例有多文書版本，模型/規則/本體可更新，樣本含真實脫敏、文獻和合成來源。
- When 凍結評測批次並稍後運行。
- Then 固定樣本/來源類別、證據及規則/知識/本體/模型/提示/解析配置和指標口徑，後續變化不替換原批次；所有結果能回查當時輸入。

### AC-F008-002 · 抽樣分層與建設評測隔離

- 來源：REQ-017, NFR-001, NFR-002, PSC-008, PSC-010
- 對應 PRD 驗收：AC-019, AC-020, AC-026
- Given 同文本不同指標、同患者多文書、近重複候選和獨立標籤文件，存在開發/驗證/留出邊界。
- When 選擇樣本/分區並交給建設或 Evaluator。
- Then 保留分層與分組依據，關聯資料不跨分區洩漏；建設者不讀取標籤/留出正文，未知來源和無法確認組關係顯式記錄，合成與真實結果分開。

### AC-F008-003 · 兩名真實專家獨立保留原判

- 來源：REQ-017, NFR-004, NFR-005, PSC-008, PSC-009, PSC-010
- 對應 PRD 驗收：AC-019, AC-017, AC-024
- Given 兩位不同獲派專家和同一身份重複提交；原判可能互異。
- When 分別保存問題、證據、嚴重度與無法判斷。
- Then 身份/指派核對成立，保存兩份獨立原判；重複同身份不算第二名專家，未提交前不展示對方原判誘導；提交/審計一致，歷史不可被仲裁覆蓋。

### AC-F008-004 · 仲裁追加並保留原始一致性

- 來源：REQ-017, NFR-002, NFR-003, NFR-004, PSC-009, PSC-010, PSC-011
- 對應 PRD 驗收：AC-019, AC-021
- Given 凍結樣本兩份原判不一致，含高風險無法判斷，專家可追加裁決。
- When 提交仲裁或繼續保留爭議。
- Then 原判與原始一致性不改，仲裁記錄理由/證據/實際主體；未決事項保持可見，高風險未決不得形成可用於晉級的通過結論。

### AC-F008-005 · 指標保留覆蓋、棄答和分母

- 來源：REQ-017, NFR-002, NFR-003, PSC-010
- 對應 PRD 驗收：AC-020
- Given 參照包含陽性/陰性，運行結果包含 TP/FP/FN/TN、陽性/陰性棄答、失敗與未運行。
- When 按固定口徑計算端到端召回、條件指標和覆蓋。
- Then 給出統計單位、分子/分母、未決/棄答/失敗與風險分層；零分母為未定義，未運行不出成績，不將棄答陽性從端到端漏檢負擔中消失。

### AC-F008-006 · 證據、解釋和建議分別評價

- 來源：REQ-017, NFR-002, NFR-003, PSC-010
- 對應 PRD 驗收：AC-020, AC-008
- Given 結論引用 ID 存在但位置錯誤、原文不支持，以及語言流暢卻不可執行或越界的建議。
- When 按凍結 rubric 由專家評價。
- Then 位置正確、主張支持、解釋可用性和建議可用性分別記錄；生成流暢/鏈接可打開不當專業正確，越界診療建議明確標錯並留案例。

### AC-F008-007 · 高風險漏報形成不可被平均分抵消的信號

- 來源：REQ-017, NFR-003, PSC-010, PSC-011
- 對應 PRD 驗收：AC-021
- Given 總體指標可能較高，但存在一項經專家確認高風險漏報或高風險未決/無法判斷。
- When 生成面向准入的風險報告。
- Then 逐項標識風險與來源，輸出明確否決/未滿足信號；不因平均分或零次觀察就聲明可晉級，不替 F009 批准。

### AC-F008-008 · 同條件比較版本並報告退化

- 來源：REQ-017, NFR-002, NFR-005, PSC-001, PSC-010
- 對應 PRD 驗收：AC-020, AC-021, AC-024
- Given Parent/Candidate 的本體、OCR或模型配置變化，固定獨立樣本及評分口徑。
- When 比較結果或重跑失敗單元。
- Then 保留兩版結果及差異歸因，不能改樣本/參照/閾值來提分；失敗/未完成也納入比較，改善與不可接受退化分別報告，原生演化 Accept 不自動成為臨床驗收。

### AC-F008-009 · 評測崗位界面與審計不洩漏

- 來源：REQ-017, NFR-001, NFR-004, NFR-006, PSC-008, PSC-009, PSC-010, PSC-013
- 對應 PRD 驗收：AC-016, AC-017, AC-019, AC-025, AC-026
- Given 被分配與未分配專家、管理/支持人員，以及長原文、多頁樣本和兩種桌面視口。
- When 定位樣本、查看證據、提交原判/仲裁併返回。
- Then 只見授權範圍，當前階段/進度/缺項真實；統計和列表同源、返回上下文保持，普通日誌無正文/答案，責任記錄不因保存失敗丟失。

### AC-F008-010 · 交接固定報告和真實未滿足項

- 來源：REQ-017, NFR-002, NFR-003, NFR-005, PSC-001, PSC-010, PSC-011
- 對應 PRD 驗收：AC-020, AC-021, AC-022
- Given 報告部分完成、缺閾值或專家參照，F009 請求評測證據，舊批次另有歷史結果。
- When 生成並交接 MetricReport/GateEvidence。
- Then 報告固定版本/範圍和實際驗證狀態，所有缺項可查；缺閾值/參照不偽造通過，舊結果不靜默套新模型或新範圍。
