# F011 · 知識圖譜工作臺規格

## 目標與可觀察結果

獲授權的醫生、質控人員和知識維護者，可以在完整原生圖譜中理解術語、病例證據和規則關係，追溯到原文及專業依據，並在保持任務上下文的前提下繼續工作。維護者可使用完整可視化設計器形成候選，由已有本體審核鏈承接。採用用戶指定的 Ontology-Playground 是明確產品約束，不能僅借用圖引擎名稱或簡化成圖片。

## 來源與範圍

- 來源需求：REQ-020, NFR-001, NFR-002, NFR-003, NFR-004, NFR-005, NFR-006；PRD U09 / DEC-012。
- 來源總規格：PSC-001, PSC-003, PSC-004, PSC-005, PSC-008, PSC-009, PSC-013, PSC-014。
- 對應 PRD 驗收：AC-027, AC-028, AC-029；貢獻既有證據、授權和桌面行為，組合仍需 PG-006。
- 包含：原生瀏覽/搜索/路徑/詳情/主題/格式/設計器；本體與術語、病例證據、規則影響；來源與版本聯動、候選編輯/交審核、受控導出和異常恢復。
- 不包含：新增自動診療、全院患者圖、公共發佈、獨立生產本體審批、HIS 回寫或教學積分系統。正式本體、規則、問題和責任對象仍由原主責模塊維護。

## 輸入輸出與迭代邊界

輸入是 F001 當前授權、F004 固定語義版本/病例上下文、F003 證據、F005 規則知識、F006 問題和實際引用記錄。F007 責任摘要如需展示只讀既有事實源，不能另算簽字狀態。

輸出是可核對的同版本圖譜與詳情、固定原文落點、明確缺口和可追溯候選；瀏覽操作不修改醫學事實。F004 消費候選，原病例/規則頁面消費導航落點。圖譜視圖內部佈局、主題、檢索定位可以獨立迭代；對象身份、層次、權限、語義投影和版本變化必須協調直接消費者。

## 用戶旅程與狀態

| 入口/前置 | 用戶動作或觸發 | 過程與反饋 | 對象狀態變化 | 可觀察結果 | 下一步 |
| --- | --- | --- | --- | --- | --- |
| 主導航與可讀語義版本 | 打開本體與術語、查概念 | 原生圖/檢查器/路徑聯動 | 僅瀏覽狀態 | 定義、綁定、約束與來源可核查 | 查看依據或創建候選 |
| 病例或規則詳情 | 查看證據關係/規則關聯 | 固定對象和版本，選擇證據 | 原任務狀態保持 | 原文與圖可並列對照 | 返回原複核/整改/規則任務 |
| 具維護權及可讀基線 | 進入 Designer、編輯、保存/提交 | 草稿、驗證結果、衝突分別顯示 | 只改變候選版本 | 同一審核流程可找到提交 | 等待專業審核，不自動生效 |
| 歷史/失效/撤權 | 切換版本或繼續請求 | 顯示歷史/拒絕/部分/失敗 | 不遷移業務事實 | 無混合版本/越權結果 | 合法原文、重試或授權恢復 |

## 功能行為

1. 進入時先確定視圖、當前授權與固定版本，得到真正可讀的對象集合後渲染；無權不先顯示舊圖。
2. 圖譜操作保留用戶指定原生能力，細節見[原生能力清單](../../architecture/ontology-playground-integration.md)；三種醫療視圖保持同一導航、命名和查看習慣。
3. 選擇節點/關係時可以核查類型、定義/原值、方向、依據、版本和缺口。直接跳轉原文或規則並可回到原任務。
4. Designer 的預覽、編輯、保存、格式驗證和專業發佈是不同動作，候選審核進入 F004。導出、鏈接和所有詳情遵守當前範圍及許可。
5. 原生渲染失敗保留明確恢復入口；原有病例證據與人工責任路徑繼續按原合同可達。

## 異常與恢復

| 情況 | 可觀察狀態 | 行為 | 恢復 |
| --- | --- | --- | --- |
| 空集合或局部無路徑 | 當前範圍內無結果 | 不推定無病情/無關係 | 改範圍或補合法資料 |
| 未覆蓋/有損映射 | 部分與具體缺口 | 不用默認值偽造專業關係 | 查看原包、修正候選 |
| 撤權/過期 | 拒絕、當前身份與恢復入口 | 清理受影響圖和可控緩存 | 重新獲得授權 |
| 語義/文書版本不匹配 | 版本衝突 | 不混用最新對象 | 選擇一致基線重載 |
| 併發保存/未保存退出 | 衝突或尚未保存 | 不覆蓋他人更新或假報成功 | 核對差異、保存/放棄 |
| 渲染/服務失敗 | 明確失敗 | 合法對象列表/原文仍有入口 | 重試原生視圖；列表不替代交付 |

## 驗收標準

本 Feature 獨立夾具證明圖譜行為；真實病例、權限、證據、候選審核的組合由 PG-006 驗證，不把上游演示或靜態截圖當完成。

### AC-F011-001 · 完整原生圖譜能力進入產品

- 來源：REQ-020, NFR-006, PSC-013, PSC-014
- 對應 PRD 驗收：AC-027
- Given 固定上游版本和相同的無敏感類型圖，含屬性、subclass、有向關係及數據綁定。
- When 在產品知識圖譜中完成 OP-01～14 適用能力的逐項操作。
- Then 原生渲染、搜索、檢查器、路徑、統計/圖例、主題、設計器及格式能力可用；差異有明確醫療適配記錄，不能僅復刻外觀、採用簡版嵌入或用圖片/卡片替代。域外動作按醫療邊界隔離。

### AC-F011-002 · 三種視圖保持類型、實例和判斷層次

- 來源：REQ-020, NFR-002, NFR-003, PSC-001, PSC-003, PSC-004, PSC-005, PSC-014
- 對應 PRD 驗收：AC-028
- Given 已批准概念、一個病例的來源斷言、規則版本、模型候選、專家意見及缺證據關係。
- When 切換本體、病例證據、規則影響並選擇節點/邊。
- Then 每種對象保留真實身份、方向、語境、判斷層次和來源；缺口明確，未知基數不變為默認一對多，病例實例不變成 OWL 類，圖連通不成為醫學事實或專業確認。

### AC-F011-003 · 圖節點回查固定原文與規則

- 來源：REQ-020, NFR-002, PSC-001, PSC-003, PSC-004, PSC-005, PSC-014
- 對應 PRD 驗收：AC-028
- Given 同一問題關聯入院與出院兩個版本段落、PDF 頁級定位及規則條款，其中一個定位失效。
- When 從問題圖選擇證據並打開原文/規則詳情。
- Then 可用引用回到對應源版本和真實位置，頁級定位不冒充字符級；失效項說明缺口，不靜默指向最新內容；並列顯示來源事實、規則/模型與專業意見。

### AC-F011-004 · 有向路徑、搜索與範圍表達一致

- 來源：REQ-020, NFR-002, NFR-006, PSC-003, PSC-013, PSC-014
- 對應 PRD 驗收：AC-027, AC-028
- Given 中文名、批准別名、同名不同概念、單向邊、孤立節點和部分加載子圖。
- When 搜索、選擇起終點、查找路徑並聚焦/退出鄰域。
- Then 對象不因同名合併，原生有向路徑及高亮一致；無路徑/同端點明確反饋，部分範圍可見；路徑只是已有關係導航，查詢無命中不捏造病例統計或診斷答案。

### AC-F011-005 · 原生設計器修改候選並承接審核

- 來源：REQ-020, NFR-004, NFR-005, PSC-003, PSC-009, PSC-014
- 對應 PRD 驗收：AC-029
- Given 知識維護者從已批准 S1 建立候選，另一人已保存更新版本。
- When 編輯實體/屬性/關係、撤銷重做、驗證、預覽、保存和提交審核，另嘗試提交過期修改。
- Then 原生編輯/預覽完整可用，中文名稱可讀；保存形成可追溯候選，過期修改拒絕並保留核對入口；原生驗證/應用預覽不發佈正式本體、不寫病歷或改變簽字。提交進入 F004 同一審核流程。

### AC-F011-006 · 導入導出不吞併本體語義

- 來源：REQ-020, NFR-002, NFR-003, PSC-003, PSC-014
- 對應 PRD 驗收：AC-029
- Given 原生 JSON、支持的 RDF/XML、含中文/外部 IRI/複雜公理的正式 Turtle/SHACL 包，以及語義缺失輸入。
- When 導入、查看圖/RDF、導出子集或完整包後重讀。
- Then 原生支持子集可核對往返；Turtle 經正式適配而不冒稱原生支持，未表達部分有損失清單和原文引用，不靜默覆蓋正式包；實例圖不能導出成 OWL 類。中文顯示名與 Fabric 專項校驗分離。

### AC-F011-007 · 圖譜所有入口遵守當前對象授權

- 來源：REQ-020, NFR-001, NFR-004, PSC-008, PSC-009, PSC-014
- 對應 PRD 驗收：AC-029
- Given 兩責任組病例和只能看術語的維護身份；部分授權在瀏覽中到期。
- When 搜索、鄰居展開、路徑、詳情、深鏈接、導出及切換身份。
- Then 服務器只返回當前可讀對象、關係和計數，所有派生動作再次校驗；撤權清理應用緩存/舊圖並限制後續讀取，拒絕可審計，不能全圖下發後隱藏或由圖入口繞過原文權限。

### AC-F011-008 · 域內分享、導出與來源許可

- 來源：REQ-020, NFR-001, NFR-004, PSC-008, PSC-009, PSC-014
- 對應 PRD 驗收：AC-029
- Given 病例實例圖、可導出本體、受限詞表和上游 URL 載荷/GitHub 提交功能。
- When 複製鏈接、下載 PNG/JSON/RDF/正式包或提交候選。
- Then 業務鏈接無病例載荷且再次鑑權；導出按用途/許可審計，圖像與投影不冒充完整正式本體；醫療環境不向公共站/倉庫提交內容，源碼版權/依賴通知保留。

### AC-F011-009 · 版本變化不會混合圖、來源和歷史判斷

- 來源：REQ-020, NFR-002, NFR-005, PSC-001, PSC-003, PSC-004, PSC-005, PSC-014
- 對應 PRD 驗收：AC-028, AC-029
- Given S1 被舊運行引用，S2 新發布、文書另有新版本，瀏覽器還持有舊圖請求。
- When 查看歷史、切換當前、響應亂序到達或舊投影已不可用。
- Then 圖/詳情/來源使用同一固定版本集合，丟棄不匹配舊響應；歷史不漂移、不繼承新簽字；失效說明原因且保留允許的原文/人工路徑。

### AC-F011-010 · 大圖原生策略與可到達性

- 來源：REQ-020, NFR-002, NFR-006, PSC-013, PSC-014
- 對應 PRD 驗收：AC-027
- Given 999/1000/1001 個元素邊界及更多對象的中文圖，含長標籤和多重邊。
- When 加載、佈局、搜索第 100 項後的對象、打開詳情、切換主題並連續切換圖。
- Then 保留原生規模佈局與限制提示，授權對象可檢索到，部分加載與未知總數不偽稱全量；交互和內存表現按凍結設備預算記錄，不能以刪掉核心交互獲得性能通過。

### AC-F011-011 · 簡潔平臺中的連續工作與無障礙

- 來源：REQ-020, NFR-006, PSC-013, PSC-014
- 對應 PRD 驗收：AC-027, AC-028
- Given 1280×800 和 1440×1000 下，從非第一頁病例列表或規則詳情進入圖，含長中文名和衝突風險。
- When 查看原生畫布/Inspector/並列證據，用鍵盤和快捷鍵選擇對象，減少動態效果後操作並返回。
- Then 主畫布、名稱、風險文字和動作可讀可達；Apple 式簡潔外殼不刪信息；焦點和來源對象/頁籤/篩選/頁碼恢復，圖譜動作不改變業務狀態，主題/高亮兼容。

### AC-F011-012 · 失敗恢復保持證據與原工作路徑

- 來源：REQ-020, NFR-002, NFR-003, NFR-006, PSC-005, PSC-013, PSC-014
- 對應 PRD 驗收：AC-028, AC-029
- Given 原生圖渲染失敗、接口暫不可用、真正無結果、部分證據缺失和未保存候選。
- When 重試、退出圖、選擇結構化列表或返回原文/任務。
- Then 失敗/空/部分/無權限明確分開；不閃現其他病例，保存狀態真實，合法原文/人工工作可繼續；降級列表不算原生圖譜驗收通過，恢復仍綁定原範圍與版本。

## 開放問題

業務行為與範圍已由 U09 明確；本規格沒有阻塞定義的問題。上游運行、性能預算、實際投影和專業發佈服務的實施前置保留在 Plan；ready 不表示任何圖譜已實現或專業驗收通過。
