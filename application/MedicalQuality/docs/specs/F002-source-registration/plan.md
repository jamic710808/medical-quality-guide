可信授權決定、服務端登記的 connector/data root、來源引用/格式、source namespace、用途/角色/許可、聲明範圍、預期輸入版本與 operation_key。

計劃給出具體實施路徑，運行依賴/接口和專業前置仍待實際證明，因此為 draft。不可用條件已定義為拒絕/受限；不能為了文件齊全把未知填成通過。

## 實現方案

### 來源合同和只讀讀取

沿既定 sources 模塊實現內部來源註冊/版本目錄，應用 PostgreSQL 保存元數據；原 SQLite 使用 mode=ro/query_only，並按批准表/字段/範圍讀取。數據根/connector 為服務端配置；登記請求不接受任意遠程 URL、任意絕對路徑或任意 SQL。讀寫路徑避免符號鏈接/規範化後越界及檢查後替換：打開實際資源時再次核對版本/邊界，對靜態來源保持穩定句柄或等價一致策略。

SourceVersion 至少包含 source_id、source_version、namespace、format、data_role/data_kind、authorized_use/授權引用、license_refs、content_digest 或 snapshot_contract、schema_digest、path_base、read_scope_ref、predecessor、registration_operation 與登記結果。來源版本、解析 run 和業務 document_version 分開，source_id 不隨每次重試更換。

ReadScope 明確表/列/選擇範圍或文件/頁/邏輯記錄範圍、purpose、授權版本/期限、預期源版本、一致性聲明與讀取上限。應用產生不暴露服務器路徑的受控 read_handle；它是資源引用，不是繞過授權的永久 bearer token。F003 執行時重新核對 F001，過期不能靠本地緩存放行。共同接口見[實施合同](../../architecture/implementation-contracts.md#contracts-source)。

### 文件與數據庫處理策略

| 來源 | 內容身份/結構 | 更新與注意事項 |
| --- | --- | --- |
| 靜態 PDF/JSON/XML/PNG/HEA/DAT | 摘要、原格式/字節與必要配對，路徑基準明確 | 新內容另登記版本；多文件資產的 manifest 共同固定 |
| JSONL.GZ | 壓縮文件摘要、既有 doc_id/origin/text_sha256、解壓邏輯定位 | 不為登記全量展開成第二套正文；源文本摘要不合並任務 |
| SQLite | 實際 schema/聲明鍵、允許查詢範圍、一致性/快照身份 | 多次獨立查詢不偽稱全庫快照；活動庫若無一致策略則受限 |
| CSV/XLSX/字典 | 原結構、字段/表頭/類型、角色與邏輯定位說明 | 元數據讀取不冒充記錄/術語意義已驗證 |
| 參考答案/留出 | 只登記必要邊界/角色與合法評測者的受控入口 | 不為 fingerprint/預覽繞過禁止讀取其正文；使用可信外部清單版本，不偽造內容哈希 |

### 登記事務與交接

API 參數結構校驗後取得當前授權；登記操作使用 operation_key/request_digest，源版本/清單、審計和必要 outbox 在同庫事務提交。資源讀取與數據庫事務並非天然原子，不能持鎖做長時哈希/讀取；先在受限作業取得固定版本觀察，再短事務核對操作/版本併發布結果，源變化則拒絕或新版本。未提交臨時結果不可供 F003 使用。

只觸發已登記且允許範圍的解析 Job；接入頁面顯示登記狀態/已知覆蓋，真實解析狀態由 F003 返回並明確來源。部分成功允許消費被批准且可定位的單元，缺失仍保留在清單；註冊 JSON 存在不意味著讀過全部數據。

### 逐結果落地與驗證

**AC-F002-001 / 只登記允許來源與用途。** 只讀取授權根/範圍內的來源，其他請求拒絕；客戶端不能讓服務端任意取文件/網絡資源，失敗不切未授權端點。 由 sources/registration.py、connectors.py、paths.py 承接，以 允許根/URI/符號鏈接和拒絕讀取探針測試 檢查；實際讀取清單、拒絕原因、允許用途 是必須保存的結果，不以界面提示或接口返回成功替代。

**AC-F002-002 / 文件與數據庫版本語義真實。** 文件固定內容身份，數據庫保留實際快照/一致性條件及範圍；僅有時間戳不聲明全庫同時刻版本，內容不符不會套舊版本 ID。 由 sources/versions.py、snapshot.py 承接，以 內容變化與一致性邊界合同測試 檢查；摘要/快照標識、版本差異與受限說明 是必須保存的結果，不以界面提示或接口返回成功替代。

**AC-F002-003 / 數據庫結構和業務記錄分開。** 保留實際結構、類型和聲明鍵，結構已讀不代表業務行已讀；不憑字段名推外鍵，不把記錄序號當患者 ID，原庫不寫入。 由 sources/catalog.py、sqlite_adapter.py 承接，以 只讀結構目錄與查詢範圍核對測試 檢查；真實表/字段/聲明約束、讀取粒度及未讀範圍 是必須保存的結果，不以界面提示或接口返回成功替代。

**AC-F002-004 / 路徑基準和定位口徑可回查。** 按各自基準定位且不越界，源 URL/歷史包路徑不當本地文件；邏輯記錄與物理行/表頭計數分開，定位不足明確受限。 由 sources/locators.py、catalog.py 承接，以 雙路徑基準及邏輯記錄口徑夾具測試 檢查；固定源句柄、路徑/計數說明和錯誤定位拒絕 是必須保存的結果，不以界面提示或接口返回成功替代。

**AC-F002-005 / 來源性質與評測角色隔離。** 角色、性質、用途和許可沿源保存；答案/留出僅交合法評測方，建設者不探讀正文；未知不自動標生產可用，公開/合成不升級為生產證據。 由 sources/roles.py、usage.py 承接，以 分角色登記與建設讀取隔離測試 檢查；角色矩陣、建模集合與零答案讀取探針 是必須保存的結果，不以界面提示或接口返回成功替代。

**AC-F002-006 / 內容重複不混淆業務身份。** 同一有效操作返回既有結果，內容族可以識別但不合並不同來源/任務；請求摘要衝突拒絕，責任記錄與登記結果一致。 由 sources/repository.py、registration.py 承接，以 重複/併發與身份分離事務測試 檢查；operation、來源/版本唯一性與不同任務關係 是必須保存的結果，不以界面提示或接口返回成功替代。

**AC-F002-007 / 接入覆蓋包含失敗和未讀。** 範圍及計數單位可對賬，成功/失敗/未讀及未知明確；空範圍不同於未知或全病歷無問題，不刪失敗項製造完整成功。 由 sources/manifests.py、results.py 承接，以 混合接入覆蓋與空/未知範圍測試 檢查；聲明清單、單位、實際統計和未完成項 是必須保存的結果，不以界面提示或接口返回成功替代。

**AC-F002-008 / 更新與撤權保留歷史並限制新讀取。** 新內容生成新版本，舊句柄不能讀取新字節冒充舊來源；撤權限制當前訪問，歷史記錄保留但回查仍需授權，變化通知帶影響範圍。 由 sources/changes.py、read_handles.py、outbox.py 承接，以 新舊來源/撤權與舊句柄消費測試 檢查；版本鏈、失效/拒絕與變更事件 是必須保存的結果，不以界面提示或接口返回成功替代。

**AC-F002-009 / 向解析方交付穩定受限合同。** 消費者得到相同身份/版本/用途/結構和回查入口，無法解釋的版本或過期條件明確拒絕；登記成功不宣稱解析/醫學驗收成功。 由 sources/contracts.py、handoff.py、API 接入結果 承接，以 最小真實 F002→F003 消費合同測試 檢查；請求/響應、實際回查及拒絕結果，註明替身範圍 是必須保存的結果，不以界面提示或接口返回成功替代。

### 上下游與獨立驗證

輸入：可信授權決定、服務端登記的 connector/data root、來源引用/格式、source namespace、用途/角色/許可、聲明範圍、預期輸入版本與 operation_key。

輸出：SourceVersion、SourceCatalog、ReadScope/AllowedReadHandle、RegistrationResult 和覆蓋/失敗項；F003 按固定版本讀取，下游回查重新核對當前授權。

初次可用顯式合成夾具檢驗字段/狀態和失敗語義；真實連接與業務/專業條件具備後再做組合驗收。對接時固定 request/operation、對象/Schema 版本、允許範圍、狀態/原因和證據引用，當前授權在執行/恢復時重驗。

1. 核對下列 OQ 與相鄰合同，在項目內固定實際依賴/服務角色；明確合成夾具和正式樣本/用途，先處理實現就緒阻塞。

3. 為 [F002 用例](../../../evals/F002.json)綁定真實檢查，運行其對應最窄路徑；沒有執行的場景保留未運行，不能勾選任務。
4. 由 T010 彙總局部證據，並在相鄰真路徑具備後執行[產品套件](../../../evals/product.json)相應組合門檻，數據/醫學/身份/生產責任分別核對。

## 回退策略

撤回未完成登記/發佈的派生可見性，保留原件與已提交來源/責任記錄；舊版本回查仍執行當前授權。輸入內容已經變更時不能恢復舊句柄讀取新內容。重試同操作先對賬，不重新複製整套數據，不清空源目錄或來源歷史。
