# F006 · 聯合質控與證據解釋規格

## 目標與可觀察結果

把當前範圍的規則檢查、知識依據與跨段語義候選組織成可複核問題，說明產生環節和版本；證據不足、衝突或失敗時停止相應自動推進，保留人工可處理的材料與恢復前提。

REQ-006 / S01-07 的系統與專家職責混淆，落實為規則/檢索/模型分工；REQ-007 / S01-08 的結論缺依據，落實為問題到同版本原文的證據鏈；REQ-008 / S01-09 的未知當通過，落實為逐檢查覆蓋、無法判斷與失敗關閉。

本規格承接用戶本次選型落盤與 Feature 補充請求，業務邊界沿用已確認 PRD / PSC。ready 表示行為可進入規劃；[Plan](plan.md)為 draft，運行條件尚未驗證，Feature 仍 planned。

## 來源與範圍

- 來源需求：REQ-006, REQ-007, REQ-008, NFR-001, NFR-002, NFR-003, NFR-005。
- 來源總規格：PSC-001, PSC-002, PSC-004, PSC-005, PSC-008。
- 本 Feature 包含：固定輸入與依據的質控運行、8 條候選規則在允許用途內的確定性處理和語義候選、問題/理由/建議/風險分流信號、原文回查、阻斷與受影響範圍重核，向 F007/F008 交接結果。
- 本 Feature 不包含：不自動診斷、不給治療指令、不無人確認改病歷，不承擔複核仲裁或簽字；不自行批准規則，不把模型分數當專業確認；不建設無限制聊天或 Agent 平臺。

## 輸入輸出與迭代邊界

- 輸入與前置條件：F004 固定 CaseContext、原表達/關係/覆蓋與語義版本，F005 適用規則/知識與檢索結果，F001 授權範圍；來自 F007 的整改新版本通過原接入鍊形成新上下文。
- 輸出、必要語義與消費方：QualityRun、逐檢查結果/覆蓋、帶來源與版本的問題候選、事實/規則/模型層次、缺口/阻斷/恢復條件；供 F007 人工處理、F008 專業評測，F004 展示同一已保存結果。
- 可獨立迭代：在上述合同不變時調整內部查詢、映射、檢索或呈現實現；不得靜默改變共享身份、狀態、適用性、原值和證據精度。
- 需要協調的變化：共同對象/版本、權限/用途、失敗與恢復、消費者可用範圍；先更新受影響總規格與 Map，技術細節在 Plan 和共享技術專題維護一處。

## 功能行為

### 主流程

1. 上下文、規則和用途具備時，對固定範圍發起質控；凍結輸入與配置，檢查適用前置，輸出實際執行範圍可見，交給規則處理和依據查詢。
2. 運行中時，執行確定性條件或跨段候選；保留每項證據、產生環節與失敗，輸出疑似問題及缺口可回查，交給質控人員複核。
3. 查看問題時，對照原文和依據；分開事實、規則、模型與專家記錄，輸出顯示有效引用或失效原因，交給F007/F008。
4. 整改後新版本時，按依賴重核受影響範圍；新運行固定新版本，舊結果不漂移，輸出機器結束不等於人工確認，交給F007 再複核/簽字前置。

### 業務規則與邊界

- 規則、檢索、模型和專家各自職責不因統一輸出被混淆；專業確認與簽字僅由後續有權主體承擔。
- 沒有配置文書清單或完整讀取範圍，不能由搜索無命中判定缺失；源未記載不等於臨床未實施。
- 每條問題固定輸入/依據版本和實際證據；字段缺失要表達原因，不能為滿足必填偽造引用、嚴重度確認或意見。
- 不確定、衝突、失敗和未執行保留在覆蓋中；阻斷自動推進仍允許授權人員查看與補充。
- 未校準風險分數不顯示誤導性精確概率；重複請求和版本變更的結果身份分開，舊簽字不繼承。

## 異常與恢復

| 情況 | 可觀察狀態 | 系統行為 | 恢復 |
| --- | --- | --- | --- |
| 輸入範圍外或規則資格不足 | 相關檢查阻斷/無法判斷 | 保留範圍與採用依據，不偷換規則 | 由 F004/F005 補齊允許條件 |
| 源缺失/定位失效/解析不完整 | 證據缺口及覆蓋 | 不判整份病歷通過 | 新版本補充後重核 |
| 模型超時/無服務/格式失敗 | 語義項未完成或無法判斷 | 保留已完成確定性項，不全局成功 | 修復域內條件後新嘗試 |
| 模型與規則/原文衝突 | 分層保留且待人工 | 不以模型高分覆蓋原事實或規則 | 交 F007/F008 核查 |
| 問題無有效引用 | 不發佈為有依據結論 | 表達原因，保留允許查看的材料 | 修復證據或人工判斷 |
| 新版本或重複請求 | 新鏈或複用有效結果 | 歷史不被覆蓋，臨時結果不當正式輸出 | 固定版本後重核受影響項 |

## 驗收標準

以下 AC 說明本 Feature 的貢獻。跨 Feature 的最終結果仍需 product 套件組合驗證；固定夾具和消費者替身不能代替真實專業驗收。

### AC-F006-001 · 運行固定適用範圍與完整版本

- 來源：REQ-006, NFR-001, NFR-002, NFR-005, PSC-001, PSC-004, PSC-008
- 對應 PRD 驗收：AC-006, AC-007, AC-026
- Given 同病例有舊/新上下文，規則有候選/生效版本，授權只允許當前範圍的一部分。
- When 發起指定用途的質控運行。
- Then 固定實際允許的病例/文書/規則/知識/語義/模型配置；不適用或未授權部分明確拒絕，不從最新視圖暗中換輸入。

### AC-F006-002 · 確定性規則條件與臨床結論分開

- 來源：REQ-006, NFR-002, NFR-003, PSC-004, PSC-005
- 對應 PRD 驗收：AC-007, AC-009
- Given 8 條規則的必要輸入中部分完整，部分缺清單、身份或可比較時間。
- When 執行已配置的確定性檢查。
- Then 逐項輸出條件成立、不成立或無法判斷及證據範圍；不從無檢索命中推斷臨床缺失，不生成診斷或病歷修改。

### AC-F006-003 · 跨段模型輸出保持候選性質

- 來源：REQ-006, REQ-007, NFR-002, NFR-003, PSC-005
- 對應 PRD 驗收：AC-007, AC-008
- Given 同病例片段含過敏、診斷描述、用藥文本的否定/主體/時間/假設差異及依據，必要證據也可能被資源限制截斷。
- When 執行允許的跨段語義比較。
- Then 模型只返回有來源的疑點與待確認建議，保留主體/否定/時間/條件；必要證據缺失或截斷時明確無法判斷，不自填專家結論、真實診斷或處方指令。

### AC-F006-004 · 單條問題呈現完整分層證據

- 來源：REQ-007, NFR-002, PSC-001, PSC-005
- 對應 PRD 驗收：AC-008
- Given 候選問題有病例原文、規則/知識版本和建議嚴重度；另有錯誤引用和只到頁級的定位。
- When 查看問題詳情與依據。
- Then 類型、建議/確認值區別、理由、建議、產生環節和版本可見；四層信息分開，實際定位粒度與失效明確，不能把鏈接存在視為支持主張。

### AC-F006-005 · 失敗與部分覆蓋禁止自動通過

- 來源：REQ-008, NFR-003, PSC-002, PSC-005
- 對應 PRD 驗收：AC-003, AC-009
- Given 同運行有有效證據、定位失效、未解析文書和模型失敗；另有範圍衝突。
- When 彙總質控或嘗試自動推進。
- Then 保留未判斷/未執行分母、阻斷原因及受影響範圍；不能以其他項成功判整份通過，授權人工仍可查看與補充材料。

### AC-F006-006 · 風險分流不替代專業確認

- 來源：REQ-008, NFR-003, PSC-005
- 對應 PRD 驗收：AC-009
- Given 規則/模型產生原生分數，部分沒有校準記錄或適用範圍不匹配。
- When 展示疑點與分流信號。
- Then 未校準/範圍不符明確表示，不轉成虛假可信百分比；任何分數不能繞過證據缺口、人工複核或高風險爭議。

### AC-F006-007 · 整改版本、配置變化與重試可追溯

- 來源：REQ-006, REQ-008, NFR-002, NFR-005, PSC-001, PSC-004, PSC-005
- 對應 PRD 驗收：AC-013, AC-015, AC-024
- Given 舊運行已存在，F007 提交新文書或規則/模型配置改變；相同請求可重複到達，進程也可能在節點結果保存後、執行進度保存前中斷。
- When 重核受影響範圍或跨進程恢復中斷。
- Then 變化產生新運行鏈，舊依據不漂移；恢復重放不重複發佈同一有效結果，權限/版本失效明確限制；影響不明則核查聲明全範圍，機器通過不等於人工確認或繼承舊簽字，取消計算不自動撤銷業務任務。

### AC-F006-008 · 人工與專業評測消費同一結果

- 來源：REQ-007, REQ-008, NFR-002, NFR-003, PSC-005
- 對應 PRD 驗收：AC-008, AC-009, AC-013, AC-020
- Given 固定運行包含候選問題、未判斷項和局部條件結果，F007/F008 為合同消費者。
- When 交接結果並投影到工作臺。
- Then 各消費者取得相同版本、證據、覆蓋和阻斷；F006 不代寫複核/仲裁/簽字，未判斷不因交接從評測分母消失。

### AC-F006-009 · 模型故障、惡意正文與假引用受限

- 來源：REQ-006, REQ-008, NFR-001, NFR-003, PSC-005, PSC-008
- 對應 PRD 驗收：AC-007, AC-009, AC-026
- Given 正文含要求越權的指令，模型可返回不存在引用或失效版本，本地服務可能失敗。
- When 構造模型輸入並處理輸出/重試。
- Then 正文作為數據，模型無改庫/簽字/任意工具權限；未授權外發拒絕，假引用不得發佈為有依據問題，錯誤日誌不復制不必要正文。

### AC-F006-010 · 本體消費與規則判定不可互相替代

- 來源：REQ-006, REQ-008, NFR-001, NFR-002, NFR-003, NFR-005, PSC-001, PSC-002, PSC-004, PSC-005, PSC-008
- 對應 PRD 驗收：AC-007, AC-008, AC-009, AC-024, AC-026
- Given 運行依賴固定語義基線，存在缺失/不匹配基線、歧義映射、空形狀圖或合法 unknown、部分證據及未經批准的建設工具請求。
- When 執行、解釋或恢復聯合質控。
- Then 實際消費匹配版本的語義/約束，區分定義推導、形狀結果、資料覆蓋、規則三值判定和模型候選；缺本體/關鍵條件不能繞過或以空結果通過；運行工具只讀且受當前授權，版本變化不改舊結果，獨立原文/人工路徑保留。
