# 一期全項目評估與驗收計劃

本計劃把 [PRD](PRD.md) 的 20 REQ、6 NFR、29 AC 和 [Product Spec](specs/product-spec.md) 的 14 PSC 接到 11 個 Feature 的正式用例及產品組合門檻。它定義如何證明需求滿足，不能替代實際實現、專家判斷或上線責任。U10 開發輪已綁定 133 條用例，實際命令和結果見[開發報告](verification/development-report.md)及逐 Feature/產品臺賬；不是所有專業或擴大組合都已通過。

## 1. 五種結果不能互相替代

| --- | --- | --- | --- |

## 2. 樣本、角色和數據隔離

評測數據按實際來源分組：公開脫敏醫院數據、文獻病例、合成工程夾具、獲准目標醫院資料。現有英文/公開病例不直接證明中文成人肺炎住院工作流；真實/合成結果分別報告，不能合成一個未經說明的臨床準確率。

- 開發/調試：允許的建設樣本，可設計規則/提示/映射和故障夾具。
- 獨立驗證/留出：問題/答案/專家理由按項目邊界隔離；Evaluator 處理，Builder/Evolver 不讀取用於調參。
- 專業原判：兩位不同實際主體各自依據原文/規則判斷，不用模型結果預選“接受”，提交前不以對方意見填答案。
- 仲裁：追加裁決引用兩份原判，不覆蓋它們；原始一致性與仲裁後參照分開。
- 臨床啟用：真實崗位、數據域、保留/簽署與關鍵人責任按 PRD OQ-003～006 落實，測試身份不代替。

按可確認患者/就診、文書家族、原文本摘要/近重複候選分組，CMQCIC 同文本不同任務不跨建設/驗證；不同 namespace 同號不能錯誤合人。分組規則/版本和樣本納入/排除原因在凍結批次保存。不能為了分組計算而探讀禁止範圍的答案。

代表樣本覆蓋八條規則、正常/問題/未知、主體/否定/歷史/計劃、來源缺失、跨段差異、掃描/表格/OCR關鍵字符、規則/本體版本/許可/撤權以及必要併發恢復。樣本量與生產門檻須由專業/業務責任者結合風險凍結；本文不發明固定 95% 或一律抽若干例的標準。

## 3. 評測批次、可重複性與責任

凍結 BatchManifest：sample/group/source/文書與證據版本、scope、rule/knowledge/semantic/mapping/shape/value-set/index、OCR/embedding/model/prompt/tokenizer/量化/採樣設置、應用/圖/Schema、指標協議、專家參照/角色和實際環境。

一次運行逐單元記錄 read/parsed/eligible/executed/abstained/failed/not_run 與支持來源，Job 成功不表示整批有效。相同配置重試保留 attempt/錯誤，不覆蓋原始結果。使用候選比較時固定同一輸入/參照和預算；不能一邊修改評測標準一邊宣稱模型進步。

參考答案/金標準是否有效必須由適用性和專業核對說明；發佈方或模型輔助標籤可以在獲准 Evaluator 研究中使用，但不是默認醫院金標準。修改參照產生新版本/批次，舊報告仍能復算。

## 4. 指標定義與分母

### 4.1 問題發現指標

首期主要檢測單位為“固定病例/文書範圍 × 規則 × 專業參照版本”；依據當前規則語義判陽性/陰性。一個單位多個重複候選不重複增加 TP；問題級匹配若啟用，須固定問題類型/規則/證據匹配和一對一分配口徑，額外重複單列誤報/冗餘，不能隨結果更改統計單位。

參照可定的陽性數 P、陰性數 N；實際判定的 TP/FP/FN/TN；陽性未給有效判斷 U_pos、陰性未給有效判斷 U_neg。後兩類細分棄答、失敗、未執行。參照尚無法確定的單位 U_ref 另列，不能硬分入陽/陰或悄悄移除。

| 指標 | 定義/分母 | 解釋與限制 |
| --- | --- | --- |
| 端到端召回 | TP / P，P=TP+FN+U_pos | 已知陽性未被有效發現的負擔保留；同時列出 FN 與 U_pos 原因 |
| 條件召回 | TP / (TP+FN) | 僅解釋系統已作明確判斷的陽性；必須與端到端召回/覆蓋同報 |
| 精確率 | TP / (TP+FP) | 針對實際候選；沒有候選時分母零為 NA，不是 100% |
| 條件特異度 | TN / (TN+FP) | 限實際判定陰性，不掩蓋 U_neg |
| 有效決策覆蓋 | (TP+FP+FN+TN)/(P+N) | 參照可定集合中實際作判斷比例；參照覆蓋另報 |
| 未判斷率 | (U_pos+U_neg)/(P+N) | 拆分模型棄答、解析/服務失敗、未運行，原因及受影響規則可查 |
| 參照覆蓋 | (P+N)/(P+N+U_ref) | 反映能被專業參照判斷的比例，不代表模型好壞 |
| 高風險漏報 | 經專家確認的高風險 FN 逐例清單與計數 | 任一即否決晉級；高風險 U_pos/未決另列且同樣不能直接晉級 |
| 誤報負擔 | FP、重複候選、每病例待核對項，分別按固定單位報告 | 不僅用總準確率反映醫生工作量 |
| 完整鏈覆蓋 | 已成功取得必要證據且完成對應檢查的單位 / 聲明單位 | 原文、解析、語義、檢索、模型各階段缺口分別可追蹤 |

零分母、未執行、未定參照/協議分別輸出 NA/not_run/未滿足及原因，不填 0 錯誤或通過。因風險分層過採而得到的樣本指標不能直接當自然分佈總體指標；若需加權，採樣方案/權重須預先固定且有真實依據。

合成算例用於核對計算：20 個參照可定單位，TP=8、FN=1、U_pos=1、FP=2、TN=7、U_neg=1。端到端召回=8/10，條件召回=8/9，precision=8/10，決策覆蓋=18/20，未判斷率=2/20。該算例不是實際醫療成績；若其中 FN 被專業參照標為高風險，不能用其他比例抵消否決。

### 4.2 證據、解釋、建議與本體/OCR 分項

| 維度 | 核對單位/方法 | 必須保留的失敗 |
| --- | --- | --- |
| 來源/原值 | 同版字段、文本、類型、層級與原生引用往返 | 前導零、null/空白/0、單位/比較符、丟結構 |
| 解析/覆蓋 | 聲明文件/頁/邏輯記錄/通道分別對賬 | 未讀、失敗、截斷、壞頁；不能跨粒度相加 |
| OCR 關鍵字符 | 編號、數值/單位、小數點、否定/例外與原圖核對 | 流暢但錯字/數值；數字 PDF 成功不證明掃描 OCR |
| 原文定位 | locator 回放實際源記錄/段落/頁框/單元格 | 引用存在但指錯、頁級冒充精確位置、清洗後偏移錯位 |
| 主張支持 | 每條候選主張由專家核對原文/規則是否支持並含必要條件 | 錯主體/時點、遺漏否定、未提供證據、引用不支持 |
| 解釋可用性 | rubric 分項：問題/規則清楚、原文可核查、理由有支持、限制/不確定明確 | 文本相似度/可讀性高但沒有業務依據 |
| 建議可用性 | rubric 分項：針對當前文書問題、可由責任崗位執行、無額外診療/代改/代簽 | 憑空補事實、超範圍醫療建議、沒有改什麼/為何改 |
| 本體定義/映射 | CQ、概念/類實例/關係方向、綁定/值集/約束與來源 | 同名同值域即等價、有損轉換、未審核或無本體消費 |
| 形式檢查 | 實際 profile/分類/SHACL 及固定版本、目標範圍報告 | 空圖/unknown 結構合法卻被當臨床正確；不支持公理靜默丟棄 |
| RAG | 編號/專名/改寫、允許集合內命中與支持，必要證據包/父塊/原 query | top-k 當完整集合、未批准語義擴展、撤權緩存返回 |
| Agent/恢復 | SG 節點真實工具/輸入版本、錯誤分支、重放與人工接續 | 裸 resume 批准、工具寫本體/病歷、SSE 洩漏私有狀態 |

Rubric 逐項記錄 滿足/部分/不滿足/不可評及專家理由；不將這些標籤隨意加總成臨床安全分。可選自動評分只作開發輔助，必須與專家對照並說明適用範圍。

### 4.3 專家一致性與比較

先報告兩份原判共同完成的單元數、缺判/無法判斷、原始一致率及分歧類型，再報告仲裁比例/結果。需要 Cohen kappa 等一致性統計時固定類別集合和協議；若統計條件不足或期望一致率分母退化則 NA 並解釋，不能用仲裁後全一致代替原始一致性。

候選模型、本體、OCR 或提示比較使用固定獨立樣本/參照及運行預算，列逐例改善、退化、失敗/未測和資源差異；只在結果可比較時彙總。LLM Judge 或原生 Evo 的 Accept 不具有專業准入效力。任何不可接受的高風險退化保留，不以均值改善消去。

## 7. 執行、證據與停止條件

1. 以允許的工程夾具驗證確定性合同和異常，準確標 synthetic；每類實際風險只使用能證明對應條件的方法。
2. 工程入口存在後在 evals 的 checks 定義真實 argv 或可重複 manual procedure/evidence，並將 check_ref 綁定。現在均為 null，後續不能機械填一個全局“通過”命令。
3. 運行時固定有效 inputs（實現、配置/鎖文件、用例/來源、數據manifest），記錄逐 EV 的 pass/fail/not_run/blocked/stale。跳過/收集零測試不算成功。
4. 一個檢查覆蓋多個 EV 時保留對應斷言結果；輸入未變的有效證據直接複用，新變更只使相關舊證據過期。
5. 固定代表樣本完成產品組合 PG-001～006，局部替身與真實端到端證據分開；業務收益/臨床資格仍需專業和真實使用觀察。
6. 高風險失敗或關鍵前置缺失保持阻斷，修復後按受影響範圍重驗；不刪難樣本、不改指標、不給虛構專家記錄。
